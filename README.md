# INDOOR EYE SENSE

Sito informativo del progetto INDOOR EYE SENSE.

## Pubblicazione con GitHub Pages

1. Apri **Settings** del repository.
2. Vai a **Pages**.
3. In **Build and deployment**, seleziona **Deploy from a branch**.
4. Scegli il branch **main** e la cartella **/(root)**.
5. Premi **Save**.

URL previsto: https://youssef673.github.io/indoor-eye-sense/

La pubblicazione può richiedere alcuni minuti.

## Contenuti

- Landing page responsive in italiano.
- Missione e tecnologie previste.
- Architettura concettuale del prototipo P1.
- Mappatura 3D e impostazione privacy.
- Roadmap e avvertenze sul carattere sperimentale.
